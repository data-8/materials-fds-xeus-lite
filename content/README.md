# Welcome to Data 8 Materials (JupyterLite)

Use the homepage calendar to open today’s items quickly, then use this guide in Lab when you need to browse by folder.

## Where everything is

- Lectures: `lectures/`
- Labs: `lab/`
- Homework: `hw/`
- Projects: `project/`

## Recommended workflow

1. Open a notebook from the calendar (or from folders above).
2. Run cells from top to bottom.
3. Save your own copy/version as needed while you work.
